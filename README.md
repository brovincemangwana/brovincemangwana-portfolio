# Brovince Mangwana | Portfolio Website

A single-page personal portfolio built with HTML, CSS, and JavaScript.

## Live Demo
https://brovincemangwana.github.io/brovincemangwana-portfolio/

## Features
- Responsive single-page layout with smooth in-page navigation
- About Me section with bio and photo
- Skills rendered dynamically from a JavaScript array
- Project cards rendered dynamically from a JavaScript array of objects
- Contact section with email and GitHub link
